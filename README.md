you can read GOOPSCRIPT.md to learn goopscript and you can change community.json to change server name and stuff.

to mod classes, duplicate the Three-Eyed class folder and change the sprites. Also update the list.txt in the classes folder to include the folder name for the new class. The custom server software will automatically give any joining players the ability to use your modded classes.

To set up the server, make sure you have node installed in powershell, and write "node install" in the goops-community-server folder. 

To run the server, run "node server.js" and the server will run!
